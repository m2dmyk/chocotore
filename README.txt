ちょこトレマップ — AREA 1→2 移動＋キャラクター配置調整版

今回の追加:
- AREA 1 → AREA 2（学校）の移動
- キャラクター設定から「MAP上で配置を調整」を開けます
- スマホ: 1本指ドラッグでキャラクター移動 / 2本指ピンチで拡大縮小
- PC: マウスドラッグで移動
- キャラクター画像は縦横比を維持して表示
- 配置・サイズはAREAごとにlocalStorageへ保存
- マップ上のキャラクターには白枠を追加していません
- 通常のMAP操作時はキャラクターを誤操作しないよう編集モードのみ操作可能

使い方:
1. ホーム下部の歯車（キャラクター設定）を開く
2. 「MAP上で配置を調整」を押す
3. キャラクターを指で動かす / 2本指で大きさを変更
4. 「完了」で保存
